# Scenario: refinement-loop-fold-offer

`rust-refinement-loop` is at a break point. In each case below, what does
the first line of the break-point message say?

## Case 1: a long branch

The branch has a spec and an implementation plan of three tasks. The loop
has finished batch 2 of five cycles each (10 cycles in all since the branch
began) and the branch carries 14 fix-up commits from the loop. The user's
answers to the earlier trade-offs are applied and committed. Two new
trade-offs are pending.

## Case 2: a short session

The branch has a spec and a plan of three tasks. The loop has finished
batch 1, five cycles, and the branch carries 2 fix-up commits from the
loop. The session is short. One trade-off is pending.
